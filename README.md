# KCD2-HADU-mod
Harder Canon Duels mod for Kingdom Come: Deliverance 2

Author: 
Alexa Pantuck

Purpose:
- Adjusts combat proficiency and stats for story-important duels to make them more climactic.
- Specifically, makes the following fights harder: Zizka, Istvan Toth, Dry Devil, and Erik

Compatibility:
Any mods that effect the base stats of the above NPCs or effects their duel logic will conflict.

Installation:
Drop base folder into your KCD2/mods folder. Only the *.pak file in the data folder will be read by the game.
